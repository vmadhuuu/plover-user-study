# Plover User Study Dashboard

Static dashboard for the Plover user study.

## GitHub Pages

This repository is designed to be published as a GitHub Pages **project site**.
It will live at:

`https://<username>.github.io/<repository-name>/`

After pushing the repository to GitHub:

1. Open **Settings → Pages** in the repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select the `main` branch and `/ (root)`, then click **Save**.

The entry page is `index.html`, and `.nojekyll` tells GitHub Pages to serve the
static files directly.
